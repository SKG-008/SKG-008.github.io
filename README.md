# Virtual.Market

A property listing website with completely free hosting and storage options.

## 🆓 Free Setup Options

### Option 1: Completely Free (Recommended for beginners)
- **Hosting**: GitHub Pages (Free)
- **Storage**: Browser localStorage + compressed images
- **Cost**: $0 forever
- **Setup time**: 5 minutes

### Option 2: Free with Database
- **Frontend**: Netlify/Vercel (Free)
- **Backend**: Railway (Free $5/month credit)
- **Database**: MongoDB Atlas (Free 512MB)
- **Cost**: Free for moderate usage

## Features

- ✅ Property listings for sale and rent
- ✅ User authentication
- ✅ Image upload with compression
- ✅ Bookmarking system
- ✅ Admin panel
- ✅ Share listings on social media
- ✅ Mobile responsive design
- ✅ Completely free hosting options

## Quick Start (Free Option)

1. **Fork this repository**
2. **Enable GitHub Pages** in repository settings
3. **Access your site** at `https://yourusername.github.io/repository-name`

That's it! Your property listing website is live and completely free.

## Image Features

- **Automatic compression**: Images compressed to ~50KB each
- **Multiple images**: Up to 3 images per listing
- **Full-screen viewer**: Click images to view in modal
- **Mobile optimized**: Works perfectly on phones

## Free Tier Limits

### GitHub Pages Option:
- ✅ Unlimited listings (stored in browser)
- ✅ Unlimited users
- ✅ No bandwidth limits
- ✅ Custom domain support
- ⚠️ Data is per-device (not shared between users)

### Database Option:
- ✅ Shared listings between all users
- ✅ ~2,000-5,000 listings capacity
- ✅ Real-time updates
- ✅ Backup and restore

## Upgrade Path

Start free and upgrade when needed:
1. **Start**: GitHub Pages (Free)
2. **Scale**: Add Railway + MongoDB ($0-9/month)
3. **Production**: Paid hosting for high traffic

## Setup Instructions

See `free-setup-guide.md` for detailed setup instructions for both free options.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend**: Node.js + Express (Optional)
- **Database**: MongoDB or localStorage
- **Hosting**: GitHub Pages, Netlify, Vercel, Railway
- **Images**: Base64 compression (no external storage needed)
